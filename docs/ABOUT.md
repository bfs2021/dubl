# О проекте

Дубль — открытая бесплатная программа для любительской озвучки мультфильмов, аниме и кино. Исходный код лежит на GitHub под лицензией GPL-3.0: программу можно использовать, менять и распространять, а изменённые версии тоже должны оставаться открытыми. Готовые ролики принадлежат тебе, но права на исходное видео остаются у его владельцев: выкладывай озвучку с учётом этих прав.

Главная идея — **поставил, открыл видео, озвучил**. Монтировать, сводить и разбираться в звуке не нужно. Всё техническое делает автопилот, а от тебя нужен только голос.

## Как это работает

От видео до готового ролика пять шагов:

1. **Видео.** Добавь файл: mp4, mkv, mov или по ссылке (видео и звук скачиваются отдельно и склеиваются в mkv, поэтому ролики в HD работают). Файл с диска программа не копирует, а запоминает, где он лежит. Один проект — одно видео.
2. **Разбор.** Разбор делается один раз на всё видео:
   - программа распознаёт речь, находит, где кто говорит, и разделяет персонажей по голосам;
   - язык определяется по самой речи, а не по метке дорожки: в файлах с русским дубляжом метка часто стоит `eng`. Если речь и метка не сошлись, программа скажет об этом;
   - если в файле есть субтитры, особенно с именами персонажей, они используются сразу.
3. **Сцена.** Кликни по реплике и создай сцену. Сцена — короткий кусок, обычно от нескольких секунд до минуты. Для сцены программа отделяет голоса от фона: музыки, шагов, взрывов. Оригинальный голос потом уходит, фон остаётся.
4. **Запись.** Выбери реплику и посмотри оригинал. Можно отрепетировать, потом записать:
   - перед записью идёт отсчёт, а текст бежит по ленте, как в студиях дубляжа;
   - дублей можно сделать сколько угодно: программа сама сверит каждый с текстом и отметит ★ лучший;
   - готовый дубль можно загрузить файлом.
5. **Готовый ролик.** Автопилот подгоняет дубли под губы, ставит их в «комнату» сцены, выравнивает громкость и собирает видео. Можно сделать горизонтальный ролик, вертикальный 9:16 или квадрат, с субтитрами или без.

Несколько сцен можно склеить в один ролик.

## Что умеет

**Видео и разбор**
- Читает почти любое видео. Если звука нет или файл битый, программа честно скажет, какой файл нужен.
- Использует всё, что есть в файле: несколько звуковых дорожек, 5.1, встроенные субтитры (ASS с именами персонажей), главы.
- Распознаёт речь, делит её на реплики и группирует реплики по голосам. Голоса можно переименовывать и объединять.
- Распознаватель выбирается в Настройках → Обработка: «Авто» (по умолчанию), Whisper или GigaAM. Русскую речь «Авто» отдаёт GigaAM: он точнее ставит начало и конец реплик. Остальные языки читает Whisper. Сомнительные места русской речи Whisper перепроверяет.
- Пометки вроде «[музыка]», «АПЛОДИСМЕНТЫ» и фразы из титров репликами не считаются.
- Папка, из которой ты брал ролик, запоминается: следующий файл и готовое видео предлагаются оттуда же.
- Тяжёлые вычисления на Mac идут на видеочипе.

**Текст**
- Правки реплик (меню у имени персонажа):
  - смена персонажа у одной реплики;
  - склейка соседних реплик одного персонажа в одну и кнопка «Разделить обратно»;
  - ⌘Z (на Windows и Linux Ctrl+Z) отменяет эти правки.
  Фразу, которую распознавание разрезало пополам, программа при разборе склеивает сама. Разделить её обратно можно так же.
- Два режима сцены: **«Как есть»** (переводишь оригинал) и **«Свой текст»** (пишешь что хочешь).
- Если в файле есть русские субтитры, они сразу подставляются как перевод.
- Счётчик слогов подсказывает, влезет ли твоя фраза в рот персонажа.
- По кнопке ИИ может перевести реплику или подогнать её по длине. Сам ИИ ничего не делает, только когда попросишь.

**Запись**
- Проверка микрофона за 10 секунд: шум комнаты, уровень, перегруз, задержка. Результат запоминается.
- Репетиция без записи.
- Отсчёт и бегущая строка с текстом.
- Разбор дубля:
  - сказал ли ты весь текст;
  - нет ли в конце лишнего («давай ещё раз»), его можно отрезать.
- Почти пустую запись программа заметит и не возьмёт в ролик.

**Звук (автопилот)**
- Убирает оригинальный голос только там, где есть твой дубль. Остальные персонажи и весь фон остаются как в фильме.
- Чистит шум микрофона по снимку тишины и чинит перегруз.
- Слегка подгоняет длину дубля под губы.
- Ставит голос в «комнату» сцены.
- Подбирает громкость под оригинальный голос персонажа.
- Громкость ролика на выбор: «как в фильме» (повторяет громкость оригинала, но не тише −24 LUFS) или «для YouTube и VK».
- Помощник-режиссёр по кнопке: скажи словами «Шкипер громче» или «как по рации», и он подвинет настройки.
- Ручные ползунки спрятаны в «Тонкой настройке». Трогать их не обязательно.

**Ролик**
- 16:9, 9:16 или 1:1. В вертикальном и квадратном весь кадр сохраняется, поля размываются.
- Субтитры по выбору: перевод, русские из файла или оригинал.
- Файл с тем же именем не перезаписывается, новый сохраняется как «(2)».

**ИИ (по желанию)**

Без ИИ программа работает полностью. ИИ только помогает с текстом. Можно подключить:
- Claude Code или Codex по своей подписке;
- DeepSeek, Gemini или любую совместимую модель по своему ключу.

Ключи хранятся только на твоём компьютере, в системной связке ключей.

## Чего здесь нет — и не будет

Дубль — не студия. Чтобы им было легко пользоваться, мы сознательно не добавляем:
- ручной монтаж дорожек и спектральное редактирование;
- клонирование чужого голоса и ИИ-озвучку вместо тебя;
- подделку движения губ;
- оценку твоей актёрской игры нейросетью.

Новая функция попадает в программу, только если делает озвучку проще для любителя.

## Что нужно для работы

- **Системы:** macOS (Apple Silicon), Windows 10/11, Linux.
- **Память:** 8 ГБ можно, 16 ГБ удобно.
- **Нейросети:** при первом запуске скачиваются примерно 1,3 ГБ. Кнопка «Скачать нейросети» есть в настройках. Для русской речи при первом разборе докачивается ещё GigaAM (~220 МБ): он точнее ставит начало и конец русских реплик.
- **Микрофон:** любой. Лучше USB-микрофон и наушники, чтобы звук фильма не попадал в запись.

## Частые вопросы

**Какой формат видео лучше, mkv или mp4?**
По качеству они одинаковы: это контейнеры, внутри лежит один и тот же видеопоток. Но в mkv чаще бывают несколько звуковых дорожек и субтитры, а Дубль умеет ими пользоваться. Если выбор есть, бери mkv.

**Нужен ли интернет и что уходит в сеть?**
Для самой озвучки интернет не нужен. Он нужен в четырёх случаях:
- скачать нейросети и их модели (один раз) и модель GigaAM при первом разборе русской речи;
- скачать видео по ссылке;
- спросить ИИ о тексте, когда ты нажал кнопку (на сервис, который ты подключил сам);
- проверить ключ ИИ после сохранения.
Твои видео, дубли и проекты никуда не отправляются. В ИИ уходит только текст реплик, с которыми ты просишь помочь.

**Программа ошиблась с репликой или персонажем. Как поправить?**
Открой разбор и кликни по имени у реплики: в меню можно отдать её другому персонажу. Две соседние реплики одного персонажа склеиваются в одну, а «Разделить обратно» возвращает как было. Всё это отменяется через ⌘Z (Ctrl+Z). Текст реплики правится на шаге записи. Если ошибок слишком много, зайди в Настройки → Обработка, смени распознавание речи и нажми «Разобрать снова».

**Где лежат проекты и модели?**
В папке данных программы. Внутри `projects/` проекты, `models/` и `runtime/` модели и нейросетевой пакет, `downloads/` видео, скачанные по ссылке:
- macOS: `~/Library/Application Support/app.dubl.desktop`
- Windows: `%APPDATA%\app.dubl.desktop`
- Linux: `~/.local/share/app.dubl.desktop`

Исходные видео остаются там, где лежали. Готовые ролики сохраняются туда, куда ты укажешь на шаге «Рендер».

**Где мои ключи ИИ?**
В системной связке ключей: macOS — «Связка ключей», Windows — Диспетчер учётных данных, Linux — Secret Service (например, GNOME Keyring). В файлах проекта и настройках их нет.

**Как сообщить об ошибке?**
Открой Настройки → О программе, нажми «Скопировать сведения для сообщения об ошибке» и вставь их в новое обращение на GitHub (кнопка «Сообщить об ошибке» там же). В сведениях есть версия, система и состояние нейросетей. Ключей, путей к файлам и названий проектов в них нет.

## Словарь

| Слово | Что значит |
|---|---|
| **Проект** | Одно видео и всё, что ты с ним сделал |
| **Разбор** | Один раз на всё видео: распознать речь, найти реплики и голоса |
| **Реплика** | Одна фраза одного персонажа |
| **Голос / персонаж** | Все реплики одного говорящего, программа находит их сама |
| **Сцена** | Кусок видео, который ты озвучиваешь: несколько реплик подряд |
| **Фон** | Всё, кроме голосов: музыка, шаги, шумы. Профи называют это M&E (music & effects) |
| **Дубль** | Одна твоя запись реплики. ★ — дубль, который пойдёт в ролик |
| **Репетиция** | Прогон реплики с отсчётом и лентой без записи |
| **Бегущая строка** | Текст едет по экрану и подсказывает, когда говорить. Сделана по образцу ритмо-ленты из французского дубляжа |
| **Укладка** | Подгонка текста перевода под длину фразы и движение губ |
| **Подгонка** | Небольшое растяжение или сжатие дубля по времени, чтобы попасть в губы |
| **Комната** | Эхо и окраска звука, чтобы голос звучал «там же», где персонаж: в комнате, на улице, по рации |
| **Сведение** | Соединение твоих дублей, оставшихся голосов и фона в одну дорожку |
| **Мастеринг** | Финальная громкость и защита от перегруза |
| **Автопилот** | Делает подгонку, сведение и мастеринг без тебя |
| **Тонкая настройка** | Ручные ползунки для тех, кто хочет поправить автопилот |
| **LUFS** | Единица громкости. Тебе её знать не нужно, есть выбор «как в фильме» и «для YouTube» |
| **Шумодав** | Убирает ровный шум микрофона и комнаты по снимку тишины |
| **Перегруз** | Запись слишком громкая, звук «хрипит». Программа предупредит и аккуратно починит |
| **Задержка** | Время, за которое звук доходит до программы. Её мерит проверка микрофона, чтобы дубль встал точно |
| **5.1** | Объёмный звук из шести каналов, голоса обычно в центральном. Программа это использует |
| **MKV** | Видеоформат, который может хранить несколько дорожек и субтитров. Самый удобный исходник |
| **Нейросети** | Модели для распознавания речи и разделения звука. Работают на твоём компьютере, без интернета |
